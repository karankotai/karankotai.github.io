InfoScroll

A mobile learning feed that turns idle scrolling into swipeable concept cards and curated short videos. The app combines an Expo Router client with Supabase auth, personalized feed state, and a TypeScript content pipeline for validating and uploading generated educational cards.

What it does

Swipeable learning cards

Serves quick facts, summaries, mini threads, key insights, and did-you-know cards through a mobile feed.

Short video mode

Separates concept cards from curated YouTube shorts with dedicated feed state and video rendering.

Personalized state

Tracks seen, saved, and skipped cards in Supabase so feed results can adapt across sessions.

Build notes

Mobile client

Expo Router, React Native, Zustand, and card-specific renderers keep the feed fast and modular.

Backend

Supabase handles auth, feed tables, user card state, RPC-powered feeds, and news cache migrations.

Content pipeline

TypeScript scripts generate prompt batches, validate outputs with Zod, and upload clean card payloads.
