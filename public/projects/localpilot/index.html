LocalPilot

A native Swift macOS agent that turns your phone into a local control surface for your Mac. It serves a phone-friendly web UI over Wi-Fi and drives the pointer, clicks, scrolling, keyboard, and media keys through CoreGraphics — closer to a Stream Deck plus trackpad than a remote desktop, with no cloud in the loop.

What it does

Trackpad & gestures

Pointer movement, tap to click, double-tap, right click, and two-finger scroll are recognized in the browser and mapped to CoreGraphics events on the Mac.

Keyboard & media

Send typed text and special keys (⌫ ↵ Tab Esc arrows), along with previous/next, play/pause, mute, and volume controls driven by system-defined key events.

Local-only by design

The Mac serves the UI and binds to local network interfaces only. QR/PIN pairing and revocable device tokens are on the roadmap so control endpoints can be locked down.

Build notes

Swift agent

A single Swift Package executable synthesizes mouse, keyboard, and media key events through AppKit and CoreGraphics, then runs on the main run loop.

Phone web UI

The Mac serves the mobile page over Network.framework, streaming input over WebSocket for low latency with a per-command REST fallback when the socket is down.

Permissions & packaging

Accessibility permission gates input control and is surfaced in the UI. A build script wraps the executable into a .app bundle so macOS trust survives rebuilds.
